# Linux Command Playground

A browser-only Linux command practice and visualizer.

## Run
Open `index.html` in a modern browser.

No server, Node.js, npm, database, or backend is required.

## Safety
This is a simulation. It does NOT access the real filesystem, execute shell commands, create real users, install packages, or change real permissions.

## Three stages
1. Learn — 10 questions, tasks, solutions, and command explanations.
2. Practice — simulated terminal accepts commands and updates the visualizer.
3. Review — current state, command history, and command coverage.

## Main files
- `index.html` — layout
- `styles.css` — UI
- `app.js` — virtual Linux state + command interpreter + visualizer
